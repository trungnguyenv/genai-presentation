Let the AI grill you: handout

From the talk on 2 Dec 2026. Open this file in any browser. Nothing here needs the internet except the links.

1. Try it this week

  1. Open a new chat for your next task.
  2. Copy grill-me below and paste it in. Write your task after it, in the same message.
  3. Answer the questions. Short answers are fine: "Q1 yes, Q2 no: …".
  4. When it asks for a file, error or document, paste or attach the real thing.

IDE group (Cursor or Claude): install the real skills from mattpocock/skills instead. The pastes below are for Copilot Chat.

2. Skills for Copilot Chat

Each one is whole and self-contained. Copy and paste it at the start of a new chat, or Download .md and attach the file (+ › Upload images and files). Tip: save it in Prompt Lab so you can find it again.
